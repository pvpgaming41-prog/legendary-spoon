Settings

Runs on Puter.js — no API key needed. The first time CORE talks, a small Puter sign-in popup appears (free account, no card); after that it just works.

Face matching runs fully on-device (face-api.js) by comparing real face embeddings — not a cloud guess — and your enrolled face is saved on this device so you won't need to re-enroll on reload. Object descriptions during a scan still use the vision-capable chat model above. Live object tags in AR mode run on-device too (no network call per frame).

Powers image generation ("draw a fox in a forest"), sound generation ("generate a sound of rain"), and 3D model generation ("make a 3d model of a spaceship"). Works with no token — anonymous, free, but shares a public rate limit and can be slower. Add a free token at huggingface.co/settings/tokens (a "Read" token is enough) for a higher personal rate limit.

Stored only in this browser's local storage, never sent anywhere but Hugging Face. If you share this HTML file with anyone, remove your token first — it would travel with the file.
Turns this into a home-screen app icon that opens without a browser bar — no token or account, but the browser only offers this once the page is hosted over HTTPS (not when opened as a local file). On iPhone there's no install button at all: use Share → Add to Home Screen instead. Want an actual installable .apk file? Host this page anywhere public and run the URL through pwabuilder.com — also free, no account needed for the basic package.
