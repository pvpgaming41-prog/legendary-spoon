Brain

Runs on Puter.js — no API key needed. The first time CORE talks, a small Puter sign-in popup appears (free account, no card); after that it just works.

Camera scanning and face matching also run through this — same no-key setup, just a vision-capable model call. Live object recognition in AR mode runs on-device instead (no network call per frame).

Powers image generation — say "draw a fox in a forest" or type it. Get a free token at huggingface.co/settings/tokens (a "Read" token is enough).

Stored only in this browser's local storage, never sent anywhere but Hugging Face. If you share this HTML file with anyone, remove your token first — it would travel with the file.
